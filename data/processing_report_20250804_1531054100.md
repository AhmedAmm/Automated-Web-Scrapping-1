# Market Intelligence Summary

## Document Overview
This document outlines the key features and functionalities of Sparx Systems' Pro Cloud Server, a platform designed to enhance the accessibility and extensibility of Enterprise Architect models. The Pro Cloud Server enables hosting of Cloud Repositories, allowing users to access Enterprise Architect models without requiring the full desktop application, especially through features like WebEA for mobile and desktop access. It also supports integration with external products via a Server Based Plug-in Interface (SBPI) and offers advanced model management capabilities.

A significant value proposition of the Pro Cloud Server lies in its ability to extend the reach and utility of Enterprise Architect models. Features like Visibility Levels, which leverage database security for restricted access, and Prolaborate, a platform for delivering curated model perspectives to diverse stakeholders, democratize access to complex design information. Additionally, the Pro Cloud Server provides web-based management (WebConfig) and direct data access through OSLC RESTful APIs, streamlining integration and data exchange with other tools and systems. Overall, the information highlights how the Pro Cloud Server empowers organizations to leverage their Enterprise Architect investments more broadly and efficiently.

## Products & Services
- **Product names and descriptions**:
    - **Pro Cloud Server**: A server that hosts Cloud Repositories for Enterprise Architect. It offers additional features when licensed.
    - **WebEA**: A feature that allows users to access Enterprise Architect models on mobile devices or desktops without installing the Enterprise Architect application. It is highly requested by users, easy to deploy, runs on various systems, and requires no special hardware or additional licensing. It offers extensive configuration options for model access and actions.
    - **Integration Plug-ins (also called Server Based Plug-in Interface - SBPI)**: A framework to extend the Pro Cloud Server via plug-ins. These allow linking Enterprise Architect elements to elements or objects in external products.
    - **Visibility Levels**: A feature exclusively available for models hosted by a Pro Cloud Server that grants model managers the ability to restrict access to specific sections of a model. This is implemented using Row Level Security in Oracle and Microsoft SQL Server.
    - **Prolaborate**: Described as the "next evolution" for delivering rich models and designs to a broader audience. It allows executives, business process managers, implementers, consultants, customers, and other stakeholders to view personalized and curated model perspectives. It simplifies complexity, focuses attention, and increases accessibility for non-modelers or those primarily consuming model information. It functions as an external social platform supporting model discussions from a different viewpoint, offering dashboards, impact analysis, and other "outside the model" features for custom audiences (e.g., CEOs, CIOs, customers).
    - **WebConfig**: A web-based configuration client that serves as an alternative to the Windows-based "Configuration Client." It allows adding and configuring Cloud connections, setting up integration Plug-ins, managing floating licenses, and viewing Pro Cloud Server logs via a web browser.
    - **OSLC RESTful API (OSLC Architecture Management v2.0)**: Provides direct access to a wide range of information from Enterprise Architect Cloud Repositories.
    - **OSLC Requirements Management**: An initiative to simplify integration between Requirement Management tools, utilizing HTTP to list, add, modify, and delete requirements.
- **Service offerings and characteristics**: Offers access to Enterprise Architect models via web browsers and mobile devices, integration capabilities with external products, granular access control for models, and enhanced model delivery and collaboration for diverse stakeholders.
- **Product features and specifications**:
    - **Pro Cloud Server**: Can host Cloud Repositories. Licensed versions offer additional features.
    - **WebEA**: Mobile and desktop access to EA models without installation.
    - **Integration Plug-ins (SBPI)**: Framework for extending Pro Cloud Server functionality.
    - **Visibility Levels**: Restricts access to model sections, relies on Oracle/Microsoft SQL Server Row Level Security.
    - **Prolaborate**: Personalized/curated model views, social platform for model discussions, dashboards, impact analysis.
    - **WebConfig**: Web-based configuration for Cloud connections, plug-ins, licenses, and logs.
    - **OSLC RESTful API**: Direct access to Cloud Repository data.
    - **OSLC Requirements Management**: HTTP-based operations for requirements integration.
