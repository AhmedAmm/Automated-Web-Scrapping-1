## Document Overview
This document is a technical guide from GitHub Enterprise Cloud Docs detailing how enterprise users can access critical compliance reports. It outlines the specific types of reports available, including SOC 1 Type 2, SOC 2 (Type 1 for Copilot Business, Type 2), Cloud Security Alliance (CSA CAIQ and STAR) certifications, and ISO/IEC 27001:2013 certification, as well as GitHub.com's incident management plan. The primary purpose is to empower organizations to easily obtain and review the security and compliance posture of their GitHub Enterprise Cloud environment.

The business relevance lies in enabling enterprises to verify GitHub's adherence to industry-standard security and compliance frameworks, which is essential for due diligence, risk management, and meeting regulatory requirements. By providing clear instructions on navigating to the "Compliance" section within enterprise settings, the document ensures that customers can efficiently access these vital reports, thus supporting their own compliance obligations and fostering trust in GitHub's security practices.
