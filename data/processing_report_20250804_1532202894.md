## Products & Services
- **Product names and descriptions**:
    - **EO.workspace**: A platform for virtual applications and desktops (mentioned in document).
    - **EO.workspace Gateway**: Facilitates remote user access from outside the organization. Encapsulates all traffic in an HTTP over TLS connection, requiring only a single firewall port to be opened (mentioned in document).
    - **Session Manager**: Central and mandatory component responsible for coordinating sessions between all EO.workspace components. Provides persistence capabilities and concentrates log files for troubleshooting. Features a SOAP API for administration (mentioned in document).
    - **Application Servers**: Host end-user applications, controlled by the Session Manager. Support Windows or Linux operating systems (mentioned in document).
    - **HTML5 client**: A JavaScript client that runs directly on web browsers, requiring no external software. It is lightweight but has limitations in direct access to local devices due to browser sandbox restrictions. Works around restrictions using different mechanisms (mentioned in document).
    - **Native Client**: A standalone application for Microsoft Windows, Linux, and Apple OS X. Offers increased integration with the user's operating system, including desktop integration, seamless application windows, and direct access to external devices like disks and printers (mentioned in document).
- **Service offerings and characteristics**:
    - **Mobile Clients**: Supports native applications on Android and iOS, installable from respective App Stores, ensuring performance and user experience on mobile devices and tablets (mentioned in document).
    - **Distributed Session Manager (DSM)**: Allows deployment in multiple geographical locations and balancing of users based on availability, last seen status, load, origin, and latency (mentioned in document).
    - **Horizontal Scaling**: Environments can be scaled horizontally with multiple farms at no extra licensing cost, supporting redundancy, disaster recovery, and elasticity strategies (mentioned in document).
    - **License Optimized Cloud Deployment**: Enables leveraging cloud license optimizations and elastic resources from software vendors without lock-in, with full control over service usage (mentioned in document).
    - **On-Premise Optimized Deployment**: Allows utilization of cost-efficient on-premise datacenters for full local jurisdiction compliance, lowest user interaction latency, and best application ecosystem experience (mentioned in document).
    - **Disaster Recovery Optimized Deployment**: Facilitates implementation of a cold standby disaster recovery environment at no marginal cost by utilizing cloud providers' pay-as-you-go models (mentioned in document).
